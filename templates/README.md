# Templates

Copy rather than overwrite these:

- [Learning log](learning-log.md): daily state and retrieval practice.
- [Experiment/report](experiment.md): pre-registration through results.
- [Paper review](paper-review.md): claims and a falsifying experiment.
- [Contribution](contribution.md): minimal reproducer and upstream status.

Keep personal records under `private/` if needed. Empty result fields mean unmeasured; do not populate them with forecasts. The interactive app can export a Markdown learning record; assessed code and raw experiment evidence still belong in project artifacts.
