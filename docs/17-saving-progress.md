# Save your progress and your place

The course automatically saves quiz attempts, confidence, review schedules, module notes, submodule notes, lab evidence notes, and hardware choices in your browser's persistent local storage. Closing a tab or restarting the browser normally preserves them. No account is required, and this information is not uploaded to the course server.

## Bookmark your place

Use your browser's bookmark command or Copy bookmark link on a course page. The link remembers the page, module or submodule encoded in its URL. It does not contain your answers or notes.

When you reopen the bookmark in the same browser profile on the same domain, the course can read the progress already saved there. On another device or browser, the link opens the same lesson but does not transfer progress.

## Move to another browser or device

1. On the main course page, choose Export progress and keep `training-lab-progress.json`.
2. Open the course on the destination browser or device.
3. Choose Import backup and select the JSON file. Confirm replacing the destination's learning record.

New full backups include module progress, confidence, module notes, lab notes, submodule notes, and hardware preferences. The Markdown export is a readable tutor record, not the complete restorable backup. Older JSON backups still restore their module progress and leave existing separate lab/hardware records unchanged.

A full backup replaces the included learning records; it does not merge two people's answers. Other website storage and tutor-interface preferences are not imported. Keep backup files private if your notes contain personal information.

## Browser profiles and domains are separate

Each browser profile has its own learning record. People sharing a computer should use separate browser profiles. Localhost, llmmastery.org, the Cloudflare Pages address, and the GitHub Pages mirror each have separate storage. Export/import moves your record between them.

Clearing site data, browser eviction, or ending a private browsing session can remove local progress. Export periodically if you want a durable copy. If storage is blocked or full, the course reports the problem; preserve the backup file before trying again.
