# Walk through the experiment

Module 7: Policy gradients · Submodule 07-02

[Module overview](../../site/?module=7) · [Complete module reference](../../modules/07-rl.md)

1. Implement a two-action bandit with known rewards. Compute expected reward and its gradient exactly; compare the Monte Carlo estimator across sample sizes and random seeds. Add a baseline and measure estimator variance.
2. Implement a small finite-horizon chain environment with a known or enumerable optimal policy. Train REINFORCE, then actor-critic. Plot returns, entropy, value loss, and policy probabilities; compare to random and optimal baselines.
3. Add GAE and clipped PPO, retaining the rollout policy’s log probabilities. Test ratios equal one before an update, loss sign for positive/negative advantages, terminal versus truncated bootstrapping, padding, and minibatch aggregation.
4. Change reward scale and rollout length separately. Explain instability with evidence rather than repeatedly tuning until one seed succeeds.
