## Expected observations

The output must expose the mechanism named in the assignment, including its edge cases. Do not target a universal benchmark number. Correctness checks should match the hand-computable/reference case within a declared tolerance; stochastic/performance comparisons must include their variation and workload definition. A negative improvement is acceptable if the method and diagnosis are sound.

## If the result is surprising

Inspect budget matching, per-example outputs, exclusions, seeds, and metric denominators. Reduce to one example, one worker, or one update where appropriate. List two competing explanations and run the cheapest test that distinguishes them. Do not change several hyperparameters together.
