## Walkthrough: the actual calculation

Begin by reading and running [the numerical example](../../examples/foundations_walkthrough.py), which depends only on NumPy. From the repository root:

```bash
python examples/foundations_walkthrough.py
```

Use logits `[[ln(3), 0], [0, 0]]` and labels `[0, 1]`. Write down the probabilities `[[0.75, 0.25], [0.5, 0.5]]`. Calculate the mean loss `(-ln(0.75)-ln(0.5))/2`, approximately 0.490415. Derive the gradient `[[-0.125, 0.125], [0.25, -0.25]]` and explain both signs and the factor of two.

Now trace the implementation: subtract each row’s maximum; calculate log probabilities with log-sum-exp; select correct-class log probabilities; average their negatives. For the gradient, copy probabilities, subtract one at each correct label, and divide by batch size. Avoid clipping probabilities to hide instability.

Reimplement the same operation in a separate file without copying the function. Compare each entry with centered finite differences in float64. Sweep perturbation sizes 1e-2, 1e-4, 1e-5, and 1e-8; record the maximum absolute error. You should observe approximation error at overly large steps and possible cancellation at overly small steps, not assume smaller is always better.

Then compare against PyTorch:

```python
z = torch.tensor([[math.log(3), 0.0], [0.0, 0.0]],
                 dtype=torch.float64, requires_grad=True)
y = torch.tensor([0, 1], dtype=torch.long)
loss = torch.nn.functional.cross_entropy(z, y)
loss.backward()
print(loss.item(), z.grad)
```

Add `import math` and `import torch` in your local script. The loss and gradients should match the values above within a justified float64 tolerance. Test a common +1000 logit shift, a label swap, a mean-to-sum change, and logits `[1000,-1000]` with the second class correct. The last loss should be finite and equal to 2000.
