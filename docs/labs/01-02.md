## Walkthrough: a small nonlinear training problem

Generate points uniformly in `[-1,1]×[-1,1]`. Define the class by whether `x0*x1 > 0`: matching signs versus opposite signs. Generate 512 training and 512 validation points with different recorded random-generator states. Keep these separate; the exact same points must not occur in both sets.

Start with `Linear(2,16) → ReLU → Linear(16,2)`. Labels are integer class indices; the final layer emits raw logits. Begin on CPU with batch size 64. Print the tensor shapes, parameter count, first loss, and gradient norms before the first update.

First train on a fixed subset of 16 examples. Use AdamW with a pilot learning rate such as 1e-2 and no weight decay for this diagnostic. Give it a bounded budget, for example 1,000 steps, and inspect whether it can fit the tiny set. These values are starting choices, not guaranteed hyperparameters; if the control fails, inspect the loop before running a sweep.

Once the control works, compare SGD, momentum SGD, and AdamW. Try three learning rates for each, such as 1e-3, 1e-2, and 1e-1, while keeping the training examples, update count, batch policy, and initial model state controlled. Save the initial state and reload it for each comparison. Different optimizer families may need different tuned ranges; state whether your comparison is only exploratory.

Log training and validation loss, accuracy, step count, and actual examples processed. Evaluate with both evaluation mode and disabled gradient tracking. Retain the learning curves rather than choosing only the final favorable point. Use validation to select settings and a fresh protected test sample only for the final comparison.

**If stuck:** verify labels by plotting or inspecting quadrants; check that gradients are nonzero; confirm weights change; and inspect the learning rate. A linear classifier is a useful deliberately limited baseline for this nonlinear rule.

**Independent check:** change the label rule to a circle or another specified nonlinear boundary, predict what transfers, and repeat a small experiment. Explain why optimizer tuning and model capacity are separate questions.
